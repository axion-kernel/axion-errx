# AI 易错勘误

- 本仓库是共享错误基础库，不要把 `axion-agent` / `axion-bridge` 的应用层依赖直接搬进来。
- 通用错误码段 `1000~1999` 归共享层维护；业务私有错误码应留在各自仓库定义。
- `pkg/errx` 是唯一对外共享入口；如需内部辅助包，后续再单独论证。
- `Type` 和 `Error` 自身携带 HTTP 失败状态，通过 `HttpStatus()` 读取；领域注册自己的状态，宿主不再重复建立错误码映射。HTTP handler、日志实现和响应正文仍归消费方。

- `errx-httpcheck` 同时检查 error/status 响应封装及错误存在性分支中的固定失败状态；与错误无关的标准 HTTP 状态声明继续允许。
